Panduan Akses Halaman Invoice

https://pt-adytia.com/dashboard/invoice

Langkah-langkah

1

Buka halaman login

Buka browser (Chrome, Edge, atau Firefox), lalu ketik atau klik tautan berikut di address bar:

https://pt-adytia.com/login
Pastikan koneksi internet aktif. Halaman akan menampilkan form login dengan logo PT Adytia Putra Tehnik.
↓
2

Login ke akun Anda

Pilih salah satu cara masuk sesuai akun yang Anda miliki:

Masuk dengan Google

Klik tombol "Masuk dengan Google" di bagian bawah form, lalu pilih akun Google yang sudah terdaftar. Browser akan membuka jendela pilih akun Google secara otomatis.

Username / Email + Password

Isi kolom Username / Email dengan username atau alamat email Anda, kemudian isi Password, lalu klik tombol "Masuk".

Jika muncul pesan "Email atau password salah", periksa kembali penulisan. Pastikan tidak ada spasi di awal/akhir. Gunakan ikon mata (👁) untuk memeriksa password.
↓
3

Belum punya akun? Gunakan akun default

Jika Anda belum memiliki akun atau belum didaftarkan oleh admin, gunakan akun berikut:

Akun Default — Hanya untuk akses Invoice
Username akun-rab-invoice
Password akun-rab-invoice

⚠️ Akun ini dibagikan ke beberapa staf. Jangan ubah password akun ini. Jika Anda perlu akun pribadi, hubungi admin.

↓
4

Setelah login berhasil

Setelah masuk, sistem akan membawa Anda ke halaman dashboard utama. Selanjutnya buka halaman Invoice dengan salah satu cara:

Cara A — Akses Langsung (Paling Mudah)

Klik atau ketik langsung di address bar browser:

https://pt-adytia.com/dashboard/invoice
Cara B — Lewat Menu Navigasi

Di sidebar kiri dashboard, cari menu Penjualan → Invoice. Klik untuk membuka halaman.

Tips: Simpan link https://pt-adytia.com/dashboard/invoice ke bookmark/favorit browser agar tidak perlu mengetik ulang setiap kali.
↓
5

Di halaman Invoice

Halaman Invoice menampilkan daftar semua tagihan. Berikut hal-hal yang bisa Anda lakukan:

LIHAT

Daftar semua invoice beserta nama pelanggan, tanggal, total nominal, dan status pembayaran (Belum Dibayar / Sebagian / Lunas).

BUAT

Klik tombol "+ Tambah" di pojok kanan atas untuk membuat invoice baru. Isi nomor invoice, nama pelanggan, tanggal, jatuh tempo, dan nominal.

EDIT

Klik ikon pensil (✏) di baris invoice untuk mengubah data atau memperbarui status pembayaran.

HAPUS

Klik ikon tong sampah (🗑) untuk menghapus invoice. Akan muncul konfirmasi sebelum data dihapus permanen.

Selesai / Keluar

↩

Cara keluar (logout)

Setelah selesai bekerja, selalu logout untuk keamanan akun:

Klik foto profil / inisial nama di pojok kanan atas halaman → klik tombol "Keluar".

Jika menggunakan akun default bersama, wajib logout setelah selesai agar staf lain tetap bisa masuk.

Masalah Umum & Solusi

Masalah Solusi
Halaman tidak mau terbuka Periksa koneksi internet. Coba refresh browser (tekan F5).
"Email atau password salah" Periksa penulisan username/password. Gunakan akun default jika perlu.
Login Google tidak bisa / jendela Google tidak muncul Pastikan browser tidak memblokir pop-up. Coba gunakan login username + password sebagai alternatif.
Setelah login diarahkan ke halaman lain, bukan Invoice Normal. Klik langsung link /dashboard/invoice setelah masuk, atau buka dari menu Penjualan.
"Akun ini telah dinonaktifkan" Hubungi admin sistem untuk mengaktifkan kembali akun Anda.
Butuh Bantuan?

Hubungi admin sistem PT Adytia Putra Tehnik untuk pembuatan akun pribadi, reset password, atau masalah akses lainnya.
